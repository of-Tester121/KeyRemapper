Small app, big list of things it does

Everything runs in one window. Pick, add, done.

Pick any button by pressing it

No menus of key names. Click Pick, press the button you mean, and KeyRemapper records it exactly, including left and right Shift, numpad keys, and both mouse side buttons.

Many remaps at once

Add as many as you want. Each one shows in a list you can remove from any time.

Mouse to mouse, too

Send a side button to left or right click if you want a spare click button.

One-click on/off

Flip “Remapping ON” to pause everything without closing the app.

Remembers everything

Your remaps save automatically and load next time you open it.

Works in games

Keys are sent as real hardware scan codes, which is what most games listen for. If a game runs as admin, run KeyRemapper as admin too.

The original button stays quiet

While a remap is active, the old button is blocked, so your side button won’t also trigger Back in the browser.

Set up your first remap in under a minute

Pick the button to change

Click Pick next to “When I press”, then press the side button (or any key) you want to reassign.

Pick what it should do

Click Pick next to “Make it press” and hit the key you want instead, like B.

Add it

Click Add remap. It works immediately, system-wide. Repeat for more.

Questions people ask

Is it safe? My antivirus complained.

Remappers have to watch the keyboard and mouse to work, and some antivirus tools flag any app that does that, especially ones built with PyInstaller. The full source is in the repo so you can check it, or build the .exe yourself with the included build.bat.

Will it work in my game?

In most games, yes. If the game runs as administrator, run KeyRemapper as administrator too. Games with strict anti-cheat can flag any tool that injects input, so check the game’s rules first.

Can I remap a keyboard key to a mouse button?

Yes. Choose left or right click in the “or mouse click” box under “Make it press”.

Does it work on Mac or Linux?

Not yet. KeyRemapper uses Windows-only hooks, so it’s Windows 10 and 11 for now.

How do I undo a remap?

Select it in the list and click Remove selected, or untick “Remapping ON” to pause them all.
